# Kerem Akkan: Portfolio

Personal website of Kerem Akkan, Mathematical Engineering graduate and MSc student at Istanbul Technical University, focused on Deep Learning and Generative AI.

**Live site: [keremakkn.github.io](https://keremakkn.github.io/)**

## Featured projects

| Project | What it does | Code |
|---|---|---|
| **RM Decision Support System** | Agentic AI decision support for private banking relationship managers, built as a team for the ING Hubs Türkiye Agentic AI Hackathon | [Repository](https://github.com/ing-agenticai-hackathon/rm-karar-destek) |
| **AI Music Recommendation System** | TÜBİTAK-supported research project: audio analysis and genre prediction with TensorFlow, CNNs and Mel spectrograms | [Repository](https://github.com/keremakkn/acoustic-fingerprint-recommender) |
| **AI & AR Virtual Garment Modeling** | E-commerce concept that maps 3D clothing models onto personal body dimensions using Computer Vision and Generative AI | Not public |
| **Sporzy** | Social sports meetup platform with map integration for organizing and joining local events | Not public |
